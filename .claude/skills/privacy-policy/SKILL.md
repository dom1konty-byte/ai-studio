# Политика конфиденциальности

Не юридическая консультация — это шаблон по фактам из кода. Для бизнеса с рисками Дамиру стоит показать юристу.

## 1. Собрать факты (только из кода, не выдумывать)
В `projects/<slug>/`:
- Разрешения: `grep -n "uses-permission" android/app/src/main/AndroidManifest.xml`.
- Пакеты: `pubspec.yaml` (или `package.json` сайта) — искать: `google_mobile_ads`, `firebase_*`, `in_app_purchase`, `http`/`dio`, `shared_preferences`, `sqflite`, `geolocator`, `camera`, аналитику.
- Сайт: поля формы, куда уходят (`formEndpoint`), счётчики (Метрика/GA), cookies.
- Таблица фактов → `docs/privacy-facts.md`: данные | зачем | где хранятся | кому передаются (сторонний сервис) | можно ли удалить.

## 2. Текст: `projects/<slug>/privacy/index.html` (RU) и `privacy/en.html` (EN)
Разделы:
1. Кто владелец (имя/ник разработчика, контакт — почта, которую даст Дамир).
2. Какие данные собираем (из таблицы). Ничего не собираем → так и написать.
3. Зачем.
4. Где хранятся (на устройстве / сервер — какой).
5. Третьи стороны со ссылками на их политики: AdMob → https://policies.google.com/privacy , Firebase → https://firebase.google.com/support/privacy.
6. Реклама и рекламный ID; как отключить персонализацию.
7. Дети: приложение не предназначено для детей до 13 лет (если так).
8. Права пользователя: доступ, удаление, контакт для запроса.
9. Изменения политики, дата вступления в силу.
Простой язык, без «и т.д.», без обещаний, которых код не выполняет.

## 3. Data safety (Play Console) → `docs/data-safety.md`
Для каждого типа данных: собирается? передаётся? обязательно/по выбору? шифруется при передаче? можно удалить? цель. AdMob: «Идентификаторы устройства — собираются и передаются, реклама/аналитика».

## 4. Публикация
Нужен публичный URL (https). Варианты: GitHub Pages для папки `privacy/`, или на сайте студии/клиента. Публикация — после ✅ (`approval-gate`). URL → в Play Console и в приложение (экран «О приложении»).

## Проверка
Каждый пакет, работающий с данными, упомянут; разрешения объяснены; дата и контакт указаны; RU и EN совпадают по смыслу.
