# Новый проект

1. Узнай у Дамира (если не сказал): **имя проекта** (как он хочет, по-русски можно) и **тип**:
   - `app` — Android-приложение (Flutter)
   - `site` — сайт / лендинг
   - `windows` — программа для Windows (Flutter desktop, заготовка)
   Одним сообщением, коротко. Можно добавить 1 строку «о чём проект» — пойдёт в бриф.
2. Убедись, что рабочее дерево чистое (`git status`). Есть незакоммиченное — спроси.
3. Запусти из корня репозитория:
   ```bash
   python3 scripts/new_project.py "<Имя>" <app|site|windows> --about "<о чём>"
   ```
   Скрипт: переводит имя в slug (латиница через дефис), копирует `templates/<тип>`, подставляет имя, создаёт `.github/workflows/<slug>.yml`, дописывает строку в `projects/README.md`, создаёт ветку `<slug>/start` и коммит.
   Флаг `--no-branch` — без ветки и коммита.
4. Папка уже есть → скрипт остановится. Предложи другое имя.
5. Отправь ветку: `git push -u origin <slug>/start`.
6. Отчёт (3 строки): папка, ветка, следующий шаг — «Бриф: директор задаст 1–2 вопроса». Передай проект `studio-director`.
