## Чек-лист каждой страницы
- `<title>` 50–60 знаков, ключ в начале. `meta description` 150–160 знаков, с призывом.
- Один `h1`, логичные `h2`/`h3`.
- Open Graph: `og:title`, `og:description`, `og:image` (1200×630), `og:type`.
- `lang="ru"`, `meta viewport`, `link rel="canonical"`.
- JSON-LD: `Organization` / `LocalBusiness` / `Product` по смыслу.
- `sitemap.xml`, `robots.txt` с ссылкой на sitemap.
- URL латиницей через дефис.

Результат: правки в файлах сайта `projects/<slug>/` + короткий список, что сделано.
