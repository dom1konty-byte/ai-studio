# Бриф — Заметки

- О чём: личное приложение заметок для Android и iPhone (без магазинов). Заметки хранятся только на телефоне.
- Для кого: для Дамира (личное пользование).
- Главное действие пользователя: быстро записать заметку — с виджета/ярлыка на главном экране за 1–2 нажатия.
- Виджет (Android сразу, iPhone — второй версией):
  - последние 3–5 заметок списком, нажатие открывает заметку;
  - одна закреплённая заметка целиком;
  - кнопка «+ новая заметка».
- Ярлык: долгое нажатие на иконку → «Новая заметка».
- Заметка: текст + список с галочками, цвет, закрепление, поиск (решение директора; Дамир не уточнил — правит на ТЗ). Напоминания — во второй версии.
- Похожие примеры: Google Keep, упрощённый.
- Платформы: Android + iOS сразу (iOS — сборка .ipa без подписи, установка через AltStore/Sideloadly, навык `flutter-ios-personal`).
- Не путать: `bystrye-zametki` — отдельный проект для Windows; синхронизации между ними нет.
- Срок: не задан.
