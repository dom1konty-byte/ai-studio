# Новый проект

1. Узнай у Дамира (если не сказал): **имя проекта** (как он хочет, по-русски можно) и **тип**:
   - `app` — Android-приложение (Flutter)
   - `site` — сайт / лендинг
   - `windows` — программа для Windows (Flutter desktop, заготовка)
   - `bot` — Telegram-бот (на компьютере с автозагрузкой или круглосуточно в Cloudflare)
   Одним сообщением, коротко. Можно добавить 1 строку «о чём проект» — пойдёт в бриф.
2. Убедись, что рабочее дерево чистое (`git status`). Есть незакоммиченное — спроси.
3. Запусти из корня репозитория:
   ```bash
   python3 scripts/new_project.py "<Имя>" <app|site|windows|bot> --about "<о чём>"
   ```
   Скрипт: переводит имя в slug (латиница через дефис), копирует `templates/<тип>`, подставляет имя, создаёт `.github/workflows/<slug>.yml`, дописывает строку в `projects/README.md`, создаёт ветку `<slug>` (одна на весь проект) и коммит.
   Флаг `--no-branch` — без ветки и коммита.
4. Папка уже есть → скрипт остановится. Предложи другое имя.
5. Отправь ветку: `git push -u origin <slug>`.
6. Отчёт (2 строки): папка, ветка. Затем — **стартовый текст** из вывода скрипта (блок «Стартовый текст для новой сессии»), дословно, в блоке кода, с пометкой: «Открой новую сессию Claude Code и вставь это».
7. В этой сессии проект дальше не вести (1 сессия = 1 проект). Исключение — Дамир просит продолжить здесь.
