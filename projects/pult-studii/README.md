# AI Studio (бывшая «Рубка», пульт студии)

Программа Windows (Flutter desktop) · папка `projects/pult-studii/` · ветка `pult-studii`.

Шаг 1: доска проектов (этап, «ждёт да», сборка, «Скачать»), чат с директором (Claude Code CLI), кнопки «Да»/«Поправить», сводка «что сделано с телефона», экран «Настройка».
Шаг 2: несколько проектов сразу (у каждого своя папка — git worktree), вкладка «Офис», «+ Новый проект», «Продолжить на телефоне», «Открыть для телефона» (Remote Control).

## Как поставить (для Дамира)
1. На GitHub: вкладка Actions → запуск «pult-studii» (последний зелёный) → внизу Artifacts → скачать `AI-Studio-setup` (zip), распаковать, внутри `AI-Studio-setup.exe`.
2. Запустить `AI-Studio-setup.exe`. Windows SmartScreen скажет «Система Windows защитила ваш компьютер» — нажми «Подробнее» → «Выполнить в любом случае» (программа без платной подписи, это нормально).
3. Права администратора не нужны: AI Studio ставится в `%LOCALAPPDATA%\Programs\AI Studio`. В конце оставь галочки «Ярлык на рабочем столе» и «Запустить AI Studio».
4. При первом запуске откроется «Мастер первого запуска»: сам ставит Git, Node.js, GitHub CLI, Claude Code (и Python), помогает войти в GitHub и Claude и скачивает папку студии (`%USERPROFILE%\ai-studio`). Нужен интернет и аккаунты GitHub и Claude. Когда всё готово, мастер закрывается. Открыть снова: «Настройка» внизу списка проектов.
5. Удалить: Параметры Windows → Приложения → AI Studio.

Microsoft Store не нужен: если winget нет или он не сработал, мастер сам скачивает Git, GitHub CLI, Node.js, Python и Claude Code с официальных сайтов (подпись файла проверяется перед запуском; Windows может спросить разрешение — нажми «Да»).

Ручная установка программ, если мастер не справился: `winget install --id Git.Git -e`, `OpenJS.NodeJS.LTS`, `GitHub.cli`, `Python.Python.3.12`, `Anthropic.ClaudeCode` (или `npm install -g @anthropic-ai/claude-code`); входы: `gh auth login`, `claude`.

## Запуск
- Первый запуск: мастер сам скачивает студию; свою папку можно указать в шаге «Папка студии» → «Указать папку вручную» (нужны `.claude/agents` и `projects/README.md`). Путь хранится в `%APPDATA%\pult-studii\state.json`.
- Из исходников (Windows): `flutter create --platforms=windows --org com.aistudio --project-name pult_studii .` (один раз), потом `flutter run -d windows`.
- Сборка: `flutter build windows --release`; в GitHub — Actions → «pult-studii»: артефакт `AI-Studio-setup` (установщик) и `pult-studii-windows` (папка с программой).
- Установщик локально (Windows, Inno Setup 6): `iscc /DMyAppVersion=1.0.0 installer\setup.iss` → `installer\output\AI-Studio-setup.exe`. Версия берётся из `pubspec.yaml`.
- Проверки: `flutter analyze`, `flutter test`.

## Как работает
- Офис: основная папка `ai-studio`, ветка `ai-office` (нет ни локально, ни на GitHub — создаётся от `origin/main`). Проект: своя папка `<рядом с ai-studio>\ai-studio-wt\<slug>` (`git worktree add`, существующая переиспользуется). При открытии чата: `git fetch origin`, `pull --ff-only` (если нет правок).
- Чаты разных проектов работают одновременно: у каждого свой процесс `claude` и свой `session_id`. На карточке — «директор работает» и «новое N» (коммиты с телефона). Закрытие окна останавливает все процессы.
- Сессия привязана к папке: у проекта, начатого в шаге 1 в основной папке, старый разговор сбрасывается (в ленте «Новая папка — начинаю новый разговор»).
- Первое сообщение нового разговора идёт со стартовым текстом: `Проект: <Имя> (<slug>). Ветка: <slug>. Задача: …` / `Офис студии. Ветка: ai-office. Задача: …`.
- «+ Новый проект»: имя, тип, идея → сообщение Офису (`/new-project`) → когда в списке появился новый проект, AI Studio создаёт его папку и открывает чат с первым вопросом директора.
- «Продолжить на телефоне»: копирует стартовый текст; если в папке есть незакоммиченное или неотправленное — предупреждает и предлагает отправить директору «Закоммить и запушь всё».
- «Открыть для телефона»: окно терминала (`wt.exe`, иначе `cmd`) с `claude --resume <id> --remote-control`; пока оно открыто, чат в AI Studio закрыт, кнопка «Я закрыл терминал — вернуться». Если чата не видно в приложении Claude, в терминале введи `/remote-control`.
- Ограничение: спецсимволы `& ' , = ! %` в имени пользователя Windows мешают вложениям (путь к папке вложений не проходит проверку).
- Длинные пути Windows: перед первой папкой проекта AI Studio выполняет `git config --global core.longpaths true`.
- Чат: `claude -p … --resume <id> --output-format stream-json …`; история — `%APPDATA%\pult-studii\chats\<slug>.jsonl` (офис — `ai-office.jsonl`).
- Клавиши: Enter — отправить, Shift+Enter — перенос, Esc — стоп, Ctrl+K — поле ввода, F5 — обновить.
- «Скачать»: `gh run download <id> -D %USERPROFILE%\Downloads\<slug>\<id>`, затем открывается папка.

## Версия 1.1 (часть A)
- Название: «AI Studio» (окно, ярлыки, установщик `AI-Studio-setup.exe`). Папка данных `%APPDATA%\pult-studii` и AppId установщика не менялись, поэтому новая версия ставится поверх старой «Рубки».
- Иконка: `assets/icon/app_icon.ico` (exe, окно, установщик; в CI копируется в `windows/runner/resources/`) и `app_icon.png` (шапка левой панели).
- Автообновление: CI зашивает номер сборки (`--dart-define=BUILD_NUMBER=<run_number>`). При запуске и раз в 6 ч программа спрашивает `gh api` про успешные запуски `pult-studii.yml` (только ветка main, push из этого репозитория); новее — плашка «Обновить»: `gh run download -n AI-Studio-setup`, тихая установка `/VERYSILENT`, перезапуск. Сборка из исходников (`BUILD_NUMBER` = 0) обновление не предлагает.
- Расходы: стоимость и токены каждого хода (событие `result`) копятся в `%APPDATA%\pult-studii\usage.json`; кнопка «Расходы» слева внизу. При лимите Claude — плашка «Лимит до HH:MM», отправка ждёт (можно «Всё равно отправить»).
- Уведомления Windows (пакет `local_notifier`): директор ответил (окно не в фокусе), проект ждёт «да», сборка готова/упала; 4 переключателя в «Настройка».
