# Дизайн — ЧистоДиск

## Стиль
«Чистая вода»: много воздуха, мягкие скругления, бирюзовый акцент, крупная цифра размера как главный герой экрана. Размер на диске показан кольцом-«каплей» (CircularProgressIndicator), которое при очистке «опустошается». Без градиентов и теней, только тонированные поверхности Material 3.

## Окно и общее
- Мин. размер 900×600, старт 1000×680, масштабируется. Material 3, `useMaterial3: true`.
- Раскладка: слева панель 240 px (логотип, пункты «Главный», «Загрузки», внизу «Открыть журнал»), справа контент. `NavigationRail` расширенный (extended).
- Сетка 8 px. Отступы: окно 24, карточки 16, между элементами 8/16. Скругления: карточки 16, кнопки 24 (стадион), чипы 8.
- Шрифт: Segoe UI (системный Windows). Заголовок 28/w600, раздел 18/w600, текст 14, подпись 12. Крупная цифра 48/w300.
- Размеры: «512 Б», «48,3 МБ», «2,1 ГБ» — один знак после запятой, запятая как разделитель, порог ГБ от 1024 МБ.
- Кнопки ≥ 48 px высотой, контраст текста ≥ 4,5:1.

## Цвета (seed для ColorScheme.fromSeed: #0F9D9A)
- Светлая: primary #0F9D9A (текст на нём белый — для кнопок использовать тёмный вариант #0B7C7A), secondary #3D5A80, фон #F4FAFA, поверхность #FFFFFF, текст #1B2B2B, подпись #566B6B, ошибка #BA1A1A, предупреждение (пропущено) #B26A00, успех #2E7D32.
- Тёмная: по системе (`ThemeMode.system`), цвета из того же seed (`brightness: dark`), ничего вручную.

## Иконки категорий (Material Icons)
Временные файлы `Icons.folder_delete_outlined`; Кэш браузеров `Icons.public`; Корзина `Icons.delete_outline`; Кэш миниатюр `Icons.image_outlined`; Логи `Icons.description_outlined`; Загрузки `Icons.download_outlined`.

## Экран 1. Главный
Сверху вниз: заголовок «Очистка», подпись «Выберите, что убрать»; блок-герой (кольцо + крупная цифра «Можно освободить: 3,4 ГБ»); список категорий (`Card` с `CheckboxListTile`: иконка, название, размер справа, подпись-пояснение); нижняя панель: кнопки «Анализ» (`FilledButton.tonal`) и «Очистить» (`FilledButton`).
Строка «Загрузки» — выключена по умолчанию, подпись «Файлы старше 30 дней», справа «Выбрать файлы →» (переход на экран 2).

```
+----------------------------------------------------+
| ЧистоДиск |  Очистка                               |
|-----------|  (  3,4 ГБ  )  Можно освободить        |
| > Главный |  [x] Временные файлы         1,2 ГБ    |
|   Загрузки|  [x] Кэш браузеров           1,9 ГБ    |
|           |  [x] Корзина               240,0 МБ    |
|           |  [x] Кэш миниатюр           48,3 МБ    |
|           |  [x] Логи                   12,5 МБ    |
|           |  [ ] Загрузки  Выбрать файлы ->        |
| Журнал    |        [ Анализ ]  [ Очистить ]        |
+----------------------------------------------------+
```

Состояния:
- До анализа: размеры «—», герой «Нажмите «Анализ»», «Очистить» неактивна (серая).
- Идёт анализ: «Анализ» неактивна, под заголовком `LinearProgressIndicator` + текст «Считаю: Кэш браузеров…», у строк ещё не посчитанных — маленький спиннер вместо размера.
- После анализа: размеры, герой с суммой отмеченного (пересчитывается при смене галочек); «Очистить» активна, если сумма > 0. Категория 0 Б — «Пусто», галочка неактивна.
- Идёт очистка: обе кнопки неактивны, прогресс «Очищаю: Логи… (3 из 5)», кольцо убывает; кнопка «Отмена» не нужна.
- Нажато: стандартный ripple M3, без самописных эффектов.
- Ошибка анализа категории: в строке иконка `error_outline` красная и «Не удалось посчитать», остальное работает.

Диалог «Закройте браузер» (`AlertDialog`, по нажатию «Очистить», если Chrome/Edge/Firefox/Яндекс запущены): заголовок «Закройте браузер», текст «Запущены: Chrome, Edge. Закройте их, чтобы очистить кэш.», кнопки «Пропустить кэш браузеров» (`TextButton`) и «Я закрыл, продолжить» (`FilledButton`, перепроверяет процессы).

## Экран 2. Загрузки
Заголовок «Загрузки», подпись «Файлы старше 30 дней. Удаляются в Корзину.»; строка «Выбрать все» + итог «Выбрано: 3 файла, 1,2 ГБ»; список (`ListView`, `CheckboxListTile`: имя, дата «12.08.2026», размер справа), сортировка по размеру по убыванию; кнопка «Готово» (возврат на Главный, включает категорию «Загрузки» и сумму выбранного).
Состояния: загрузка — `LinearProgressIndicator` «Ищу старые файлы…»; пусто — иконка `check_circle_outline` и «Старых файлов нет»; ошибка доступа — «Не удалось прочитать папку» + «Повторить»; по умолчанию ни один файл не отмечен.

## Экран 3. Итог
По центру: большая иконка `check_circle` (успех), «Освобождено 3,4 ГБ» (48/w300), строка «Удалено файлов: 1 284». Если есть пропущенные: карточка предупреждения (#B26A00 на светлом фоне) «Пропущено 17 файлов — их используют другие программы». Если браузер пропущен: «Кэш браузеров не очищен». Кнопки: «Открыть журнал» (`OutlinedButton`) и «Готово» (`FilledButton`, назад на Главный, размеры сбрасываются в «—»).
Состояния: 0 освобождено — «Нечего было удалять», иконка `info_outline`; ошибка записи журнала — подпись «Журнал не сохранён», итог всё равно показан; общая ошибка — иконка `error_outline` красная, «Очистка прервана», кнопка «Назад».

## Навигация
Левая панель переключает Главный и Загрузки. «Очистить» → (диалог браузера) → очистка → Итог (заменяет контент, панель остаётся). «Готово» → Главный.

### Анимации (общее)
- Переход между экранами: прозрачность + сдвиг на 16 px вверх, 250 мс `easeOutCubic` (`AnimatedSwitcher`/`FadeTransition`).
- Размеры в списках: счёт от старого к новому, 500 мс `easeOut`.
- Сворачивание в трей: окно уменьшается до 10 % и затухает (opacity 1→0) к правому нижнему углу (к области часов), 300 мс `easeInCubic`; затем скрывается. Открытие из трея — обратно: 10 %→100 %, 0→1, 300 мс `easeOutCubic` от угла. Если Windows не даёт менять размер плавно — запасной вариант: только затухание 200 мс.
- Системная настройка «Убрать анимации» включена — все анимации выключаются (мгновенно).
- Доступность: кнопки ≥ 48, контраст ≥ 4,5:1, у иконок-кнопок `Tooltip`.
