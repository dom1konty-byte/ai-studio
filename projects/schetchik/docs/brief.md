# Бриф — Счётчик

- О чём: простой счётчик нажатий на телефоне (Android).
- Для кого: любой, кому нужно что-то посчитать (повторы, люди, круги).
- Главное действие пользователя: нажать «+1».
- Функции: кнопка «+1»; кнопки «−1» и «Сброс»; число крупно по центру; число сохраняется после перезапуска; светлая и тёмная тема.
- Похожие примеры: стандартный Flutter-счётчик, приложения Tally Counter.
- Срок: пробный прогон (тест).
