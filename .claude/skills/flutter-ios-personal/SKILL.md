# iPhone для себя (без App Store)

Публикации в App Store НЕТ. Цель — поставить своё приложение на свой айфон бесплатно.

## Включить iOS в проекте (агент, в `projects/<slug>/`)
```bash
flutter create --platforms=ios --org com.aistudio --project-name <package> .
```
Закоммитить папку `ios/`. С этого момента workflow проекта сам собирает `.ipa` на Mac (задача `ios`) при каждом push и присылает файл в Telegram. Без папки `ios/` задача не запускается (Mac-минуты GitHub в 10 раз дороже обычных — ~20 сборок в месяц на бесплатном лимите).
- Название под иконкой: `ios/Runner/Info.plist` → `CFBundleDisplayName`.
- Иконка: `flutter_launcher_icons` с `ios: true`.
- Пакеты — только с поддержкой iOS (смотреть «Platform» на pub.dev). Нативные вещи для iOS (виджет, Siri, уведомления по расписанию) — отдельные задачи, требуют Swift/Xcode-настроек.
- Проверить без Mac нельзя (нет симулятора): полагаемся на сборку в CI и общие тесты `flutter test`.

## Установка на айфон (Дамир, один раз, компьютер Windows)
1. Поставить **iTunes** и **iCloud** с сайта Apple (не из Microsoft Store): apple.com/itunes, support.apple.com (iCloud для Windows).
2. Скачать **AltStore** (altstore.io) → установить **AltServer** на компьютер → значок в трее.
3. Айфон по кабелю → в iTunes «Доверять» → AltServer → Install AltStore → выбрать айфон → войти **своим Apple ID** (бесплатный).
4. На айфоне: Настройки → Основные → VPN и управление устройством → доверять своему Apple ID. С iOS 16: Настройки → Конфиденциальность → **Режим разработчика** → вкл.
5. Файл `.ipa` из Telegram сохранить на айфон (Файлы) → AltStore → My Apps → «+» → выбрать `.ipa`.

Альтернатива проще, но без автопродления: **Sideloadly** (sideloadly.io) на компьютере → перетащить `.ipa`, ввести Apple ID → Start.

## Ограничения бесплатного Apple ID (сказать Дамиру прямо)
- Подпись живёт **7 дней**. AltStore продлевает сам, если раз в неделю компьютер с AltServer включён и айфон в той же Wi‑Fi. Не продлилось → приложение не откроется, данные не пропадут — переустановить/продлить.
- Не больше **3 своих приложений** одновременно (AltStore считается одним из них).
- Без этого — аккаунт разработчика Apple $99/год (подпись на год, TestFlight).
