# ТЗ — Заметки

**Цель:** личное приложение заметок, где новую заметку можно записать с главного экрана за 1–2 нажатия.

**Для кого:** для Дамира (личное пользование, без магазинов).

## Функции MVP (по важности)
1. Заметка: заголовок + текст, сохраняется сама при выходе из редактора.
2. Быстрая запись: ярлык «Новая заметка» (долгое нажатие на иконку) открывает пустой редактор.
3. Виджет Android (3 вида на выбор):
   - список последних 3–5 заметок, нажатие открывает заметку;
   - одна закреплённая заметка целиком;
   - кнопка «+ Новая заметка».
4. Чек-лист: пункты с галочками (в заметке — текст или чек-лист).
5. Закрепление заметки (закреплённые сверху списка).
6. Цвет заметки (6–8 цветов).
7. Поиск по заголовку и тексту.
8. Удаление (с вопросом «Точно удалить?»).
9. Хранение только на телефоне, без интернета и сервера.

## Экраны
- **Список заметок:** карточки, поиск сверху, кнопка «+».
- **Редактор:** текст или чек-лист, выбор цвета, закрепить, удалить.
- Настроек нет: тема (светлая/тёмная) — как в системе телефона.

## Платформы и технологии
- Flutter. Android сразу; iPhone сразу как приложение (файл .ipa без подписи, установка через AltStore/Sideloadly).
- Виджет на iPhone — версия 2.
- База на телефоне: `sqflite` (простая встроенная база SQLite).
- `home_widget` — связь приложения с виджетом; `quick_actions` — ярлык на иконке.

## Критерии готовности
- [ ] Можно создать, изменить, закрепить, перекрасить и удалить заметку; после перезапуска всё на месте.
- [ ] Чек-лист: галочки ставятся и сохраняются.
- [ ] Поиск находит заметку по слову из заголовка или текста.
- [ ] Все 3 вида виджета добавляются на экран Android и показывают актуальные данные после правки заметки.
- [ ] Нажатие на заметку в виджете открывает именно её; «+» открывает пустой редактор.
- [ ] Долгое нажатие на иконку показывает «Новая заметка» и открывает редактор.
- [ ] Работает без интернета.
- [ ] `flutter analyze` и `flutter test` без ошибок; собираются APK и .ipa.

## Решения
- Виджет «закреплённая»: если закреплено несколько — показывает самую свежую.
