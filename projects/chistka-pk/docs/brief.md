# Бриф — Чистка ПК

- О чём: программа для Windows — очистка ненужного. Своё название и дизайн (не копировать чужие программы).
- Что чистит (v1):
  - временные файлы (%TEMP%, C:\Windows\Temp — что доступно без прав администратора);
  - кэш браузеров: Chrome, Edge, Firefox, Яндекс — перед очисткой попросить закрыть браузер;
  - Корзина, кэш миниатюр, логи;
  - Загрузки — отдельная категория, по умолчанию выключена: список файлов старше 30 дней с размером, галочки ставит пользователь, удаление только в Корзину.
- Как работает: Анализ (категории с размером, галочки) → Очистить → итог «освобождено X ГБ».
- Безопасность: удалять только известные папки кэша; личные файлы — никогда (кроме отмеченных в Загрузках); занятые файлы пропускать; журнал удалённого.
- Для кого: для себя (Дамир). Возможно, позже — для всех; цифровая подпись установщика пока не нужна.
- Главное действие пользователя: нажать «Анализ», затем «Очистить» и увидеть, сколько места освободилось.
- Похожие примеры: программы-чистильщики для Windows (копировать нельзя).
- Срок: без срока.
- Сборка: Flutter desktop (Windows); результат — setup.exe (Inno Setup): установка, ярлык на рабочем столе и в Пуске; кладётся в артефакты GitHub Actions. Шагов Telegram в сборке этого проекта нет.
- v2 (позже): очистка по расписанию, значок в трее, Windows Update и Prefetch (с правами администратора).
- Название: выбрать при одобрении ТЗ.
