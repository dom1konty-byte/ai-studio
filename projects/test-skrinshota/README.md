# Тест скриншота

Android-приложение · папка `projects/test-skrinshota/` · ветка `test-skrinshota`

—

- Документы: `docs/` (бриф, ТЗ, дизайн, журнал).
- Сборка APK: GitHub → Actions → «test-skrinshota» → последний запуск → Artifacts → `test-skrinshota-apk`.
- Локально: `flutter pub get && flutter run`.
- Папка `android/` создаётся командой `flutter create --platforms=android --org com.aistudio --project-name test_skrinshota .` (CI делает это сам).
