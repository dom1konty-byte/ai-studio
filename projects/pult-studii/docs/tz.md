# ТЗ — Пульт студии

## Цель
Программа для Windows 11, где Дамир ведёт чат с директором любого проекта студии и видит все проекты на одной доске.

## Для кого
Только Дамир, один пользователь, один компьютер (Windows 11).

## Главный экран
Слева список проектов (название, этап, метка «ждёт да»). Справа чат с директором выбранного проекта.

## Функции v1 (по важности)
1. Чат с директором проекта: программа запускает Claude Code CLI (командная программа Claude) в папке ai-studio, в ветке проекта. История чата каждого проекта сохраняется и открывается заново.
2. Кнопки «Да» и «Поправить» на точках одобрения (этапы с ✅).
3. Доска проектов: этап, метка «ждёт да», статус последней сборки, кнопка «Скачать» (данные из GitHub).
4. «Новый проект»: Дамир вводит идею, запускается создание проекта, дальше отвечает директор.
5. Вкладка «Офис»: чат с офисом студии (ветка ai-office).
6. «Продолжить на телефоне»: копирует стартовый текст `Проект: <Имя> (<slug>). Ветка: <slug>. Задача: …`
7. При запуске: обновление данных из GitHub и сводка «что сделано с телефона».
8. Всё, что меняется в проекте, сохраняется в git и отправляется на GitHub, чтобы продолжать с телефона.
9. При старте проверка, что есть Git, Node.js, Claude Code CLI (с входом в аккаунт) и gh (командная программа GitHub). Чего нет — понятное сообщение, что поставить.

## Экраны
Главный (список + чат), доска проектов, «Новый проект», «Офис», сообщение о проверке при старте.

## НЕ делаем в v1
- Расходы и лимиты по проектам.
- Уведомления Windows.
- Тёмная тема.
- Версии не для Windows, несколько пользователей, вход по паролю.
- Публикация программы в магазины.

## Критерии готовности
- Программа запускается на Windows 11, в окне своё название и свой дизайн.
- При запуске без Git/Node/claude/gh показано, чего не хватает.
- В списке видны все проекты с этапом; у ждущих одобрения есть метка «ждёт да».
- Сообщение в чате доходит до директора выбранного проекта, ответ виден.
- После закрытия и открытия программы история чата проекта на месте.
- «Да» и «Поправить» отправляют ответ директору.
- Доска показывает статус сборки и ссылку «Скачать» там, где есть сборка.
- «Новый проект» создаёт папку и ветку проекта и открывает чат с директором.
- «Продолжить на телефоне» копирует текст в нужном виде.
- При запуске появляется сводка изменений с телефона.
- Изменения попадают в GitHub (видны в ветке проекта).
- Проверки сборки (CI) зелёные.

## Платформа
Windows 11, Flutter desktop (подтверждено, см. docs/architecture.md). Remote Control — частично: отдельная кнопка «Открыть в терминале для телефона».

## Версия 1.1 (выбор Дамира, 2026-11-28)
1. **Автообновление.** При запуске и раз в 6 ч Рубка проверяет последнюю успешную сборку `pult-studii.yml` (ветка main, иначе pult-studii). Новее текущей → плашка «Есть новая версия — Обновить». Обновить → скачать `Rubka-setup` через gh, тихо поставить, перезапустить Рубку. Номер сборки зашит в программу при сборке.
2. **Вложения в чат.** Перетащить файл/картинку в чат, вставить картинку из буфера (Ctrl+V) или кнопка 📎. Файлы копируются в папку вложений Рубки, директор получает пути к ним и может их открыть. До 10 файлов, до 20 МБ каждый.
3. **Документы проекта.** В шапке чата кнопка «Документы» → список `docs/*.md` проекта (Бриф, ТЗ, Дизайн, Архитектура, Отчёт, Уроки), открываются красиво оформленными внутри Рубки, только чтение.
4. **QR для APK.** У проекта-приложения с готовой сборкой — кнопка «На телефон»: Рубка скачивает APK и показывает QR-код; телефон в той же Wi-Fi сканирует и скачивает APK прямо с компьютера. Раздача выключается через 15 мин или по кнопке.
5. **Иконка Рубки** — своя, в окне, панели задач, ярлыке и установщике.
6. **Расходы и лимиты.** По каждому проекту и офису: стоимость и токены за сегодня / 7 дней / всё время (по данным Claude Code; при подписке это «условная» стоимость). Если Claude сообщил о лимите — плашка «Лимит до HH:MM» и чаты ждут.
7. **Уведомления Windows.** «Директор ответил» (если окно не в фокусе), «Проект ждёт «да»», «Сборка упала / готова». Нажатие открывает нужный чат. Можно выключить в настройках.

**Критерии:** обновление ставится без ручного скачивания; картинка из буфера доходит до директора; документы открываются без GitHub; APK скачивается на телефон по QR; иконка видна везде; расходы считаются по каждому ходу; уведомления приходят при свёрнутой Рубке.
