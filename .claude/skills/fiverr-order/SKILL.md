# Заказ с Fiverr

С Дамиром — по-русски. С клиентом — тексты на английском (Дамир копирует их в Fiverr сам). Студия в Fiverr ничего не отправляет.

## 1. Разбор заказа
Дамир вставляет текст заказа / переписки. Ответ Дамиру (≤8 строк):
- Что хочет клиент (по-русски, 2–3 пункта).
- Тип: `app` / `site` / `windows`. Подходит ли нам (Flutter Android, сайт). Не подходит (iOS-публикация, сложный бэкенд, взлом, накрутки, чужой бренд) → «отказаться» + вежливый текст отказа.
- Чего не хватает → вопросы клиенту.
- Оценка: объём (S/M/L), срок в днях с запасом 30%, какой пакет (Basic/Standard/Premium).

## 2. Вопросы клиенту (англ., ≤5, одним сообщением)
```
Hi <name>, thanks for reaching out! To give you an exact quote and timeline, could you clarify:
1. ...
2. ...
Once I have this, I'll send a custom offer.
```
Типовые: целевая аудитория; примеры (ссылки) того, что нравится; есть ли тексты/лого/цвета; нужен ли сервер/логин/оплата; кто публикует в Google Play (аккаунт клиента?); срок.

## 3. Старт
- Клиент принял оффер → `/new-project "<Имя>" <тип> --about "Fiverr: <клиент>, <суть>"`.
- В `projects/<slug>/docs/fiverr.md`: клиент (ник), пакет, цена, срок сдачи (дата), число правок по пакету, требования клиента дословно (англ.).
- Этапы студии те же. ✅ одобрения даёт Дамир (он передаёт ответы клиента).

## 4. Правки
- Учёт в `docs/fiverr.md`: `Правка N/<лимит>: что просили — сделано`.
- Сверх пакета или вне ТЗ → не делать молча: Дамиру «это сверх пакета», клиенту — текст с предложением extra:
```
Happy to add this! It's outside the original scope, so I'll send a small custom extra for it.
```

## 5. Сдача (англ.)
```
Hi <name>, your <app/website> is ready! 🎉
Included: <3–5 пунктов>
Files: <APK / zip сайта / исходники> attached.
How to install/run: <1–3 шага>
Please review and let me know if you'd like any adjustments (<N> revisions included).
```
Файлы для сдачи: APK/AAB из Actions (`/release`), zip папки `site/`, исходники — только то, что в пакете.

## Правила Fiverr
- Общение и оплата — только внутри Fiverr. Не давать и не просить почту, телефон, мессенджеры, внешние платёжки.
- Не начинать работу до оплаченного заказа.
- Срок сдачи — с запасом; задержка → предупредить клиента заранее (текст через Дамира).
- Секреты клиента (ключи, пароли аккаунтов) — не в git; только GitHub Secrets / у клиента.
- В `CREDITS`/исходниках клиента — без чужого кода без лицензии.
