# Проверка бота сайт

Сайт · папка `projects/proverka-bota-sait/` · ветка `proverka-bota-sait`

—

- Сайт: `site/` (HTML + CSS + JS, без сборки). Открыть `site/index.html` в браузере.
- Локальный сервер: `python3 -m http.server -d site 8000` → http://localhost:8000
- Форма: адрес отправки — `site/site.config.json` → `formEndpoint`.
- Хостинг пока не выбран: папка `site/` подходит для GitHub Pages / Netlify / Vercel / Cloudflare Pages.
