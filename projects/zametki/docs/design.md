# Дизайн — Заметки

Flutter, Material 3 (`useMaterial3: true`), только готовые виджеты. Настроек нет, тема по системе.

## Экраны

### 1. Список заметок (главный)
Сверху вниз:
1. `SearchBar` (M3), подсказка «Поиск по заметкам», кнопка очистки появляется при вводе.
2. Заголовок секции «Закреплённые» (label, показывается только если есть закреплённые).
3. Карточки закреплённых.
4. Заголовок секции «Остальные» (только если есть закреплённые).
5. Карточки остальных (новые сверху, по дате изменения).
6. `FloatingActionButton.extended` «+ Заметка» справа снизу.

Карточка (`Card.filled`, цвет заметки): заголовок (1 строка), превью до 3 строк текста или до 3 пунктов чек-листа («☐/☑ пункт»), иконка булавки справа вверху, если закреплена. Сетка: 2 колонки на 360dp, 3 на ≥600dp, 4 на ≥900dp (`SliverGrid`/masonry не нужен, фиксированная высота по содержимому, макс. 160dp).
Нажатие — открыть редактор. Долгое нажатие не используется.

### 2. Редактор
`Scaffold` с фоном цвета заметки. Сверху `AppBar` (фон прозрачный): назад; справа иконки «Закрепить» (булавка, переключатель), «Цвет», «Удалить». Ниже:
1. Поле заголовка (`TextField` без рамки, title).
2. Переключатель типа: `SegmentedButton` «Текст | Чек-лист» (при смене текст ↔ пункты: строки превращаются в пункты и обратно).
3. Тело:
   - Текст: многострочное `TextField` без рамки на всю высоту.
   - Чек-лист: список строк `Checkbox` + `TextField`; отмеченные уходят вниз, зачёркнуты и серые; внизу строка «+ Пункт»; у строки иконка «×» удалить пункт.
4. Сохранение само при выходе (назад/жест). Пустая заметка (нет заголовка и текста) не сохраняется.

Выбор цвета: `showModalBottomSheet`, ряд из 8 кружков 48dp (`Wrap`), выбранный — с галочкой и обводкой `primary` 2dp.

Удаление: `AlertDialog` «Удалить заметку?» / текст «Точно удалить? Вернуть будет нельзя.» / кнопки `TextButton` «Отмена» и `FilledButton` «Удалить» (цвет error). После удаления — назад в список, `SnackBar` «Заметка удалена».

## Навигация
- Список → нажатие на карточку → Редактор (`Navigator.push`, стандартный переход M3).
- Список → «+» → пустой редактор.
- Редактор → назад → сохранение → Список.
- Вход извне: ярлык на иконке «Новая заметка» и «+» в виджете → пустой редактор; нажатие на заметку в виджете → редактор этой заметки (передаём id). Назад из такого редактора → список.
- Экранов настроек нет.

## Шрифты
Системный Roboto (шрифты M3 по умолчанию, ничего не подключаем).
- Заголовок экрана / заголовок заметки в редакторе: `titleLarge` 22sp, w500.
- Заголовок карточки: `titleMedium` 16sp, w500.
- Текст заметки, пункты, поиск: `bodyLarge` 16sp (в карточке `bodyMedium` 14sp).
- Подписи (секции, дата): `labelMedium` 12sp.
Масштаб шрифта системы поддерживается, текст не обрезаем жёстко (в карточках `maxLines` + `ellipsis`).

## Сетка и размеры
- Шаг 8dp. Поля экрана 16dp. Между карточками 8dp. Внутри карточки 12dp (допустимо 4/8/12/16).
- Скругления: карточка 16dp, поиск и FAB — по умолчанию M3 (поиск полностью скруглён), диалог 28dp, кружок цвета — круг.
- Все нажимаемые элементы ≥48×48dp (иконки AppBar, кружки цвета, чекбоксы с отступом).
- Контраст текста ≥4.5:1.

## Виджеты Android
Общее: фон виджета — цвет заметки (для списка и кнопки — `surface` из seed-палитры), скругление 16dp (Android 12+: системный `system_app_widget_background_radius`), внутренний отступ 12dp, текст 14sp (заголовок 16sp bold, подпись 12sp). Светлая/тёмная — по системе: два набора ресурсов (`values` и `values-night`) с цветами из таблиц выше. Данные виджетам передаёт приложение через `home_widget` при каждом сохранении заметки. Нажатие на любую область, где не указано иное, открывает приложение. Настроек и экрана конфигурации нет. Добавляется три отдельных виджета в списке виджетов Android.

### 1. «Последние заметки»
- Размер: по умолчанию 4×3 ячейки, минимум 3×2, растягивается до 4×4 (`resizeMode="horizontal|vertical"`).
- Разметка (`LinearLayout` вертикальный):
  - строка шапки: «Заметки» (14sp, primary) и справа кнопка «+» 40dp (минимум зона нажатия 48dp);
  - `ListView`/`RemoteViews` коллекция: до 5 строк (при высоте 2 ячейки показывается 3), строка: цветная полоска 4dp слева (цвет заметки), заголовок 1 строка (16sp), под ним превью 1 строка (12sp, `onSurfaceVariant`);
  - пусто: «Нет заметок. Нажмите +».
- Цвета: фон `surface` (светлая #F5FBF7, тёмная #0F1512), текст #171D1A / #DEE4E0.
- Нажатие на строку — открыть эту заметку; на «+» — пустой редактор.

### 2. «Закреплённая заметка»
- Размер: по умолчанию 3×3, минимум 2×2, растягивается до 4×4.
- Разметка: фон — цвет заметки (из таблицы, по теме); сверху заголовок (16sp bold, 1–2 строки) с иконкой булавки 16dp; ниже текст или пункты чек-листа (☐/☑ + текст), сколько влезает, остальное обрезается `ellipsis`.
- Показывает самую свежую из закреплённых (решение ТЗ).
- Пусто (нет закреплённых): фон `surface`, текст «Закрепите заметку в приложении» по центру.
- Нажатие — открыть эту заметку.

### 3. «Новая заметка»
- Размер: по умолчанию 2×1, минимум 1×1 (в 1×1 только значок), растягивается по горизонтали до 4×1.
- Разметка: `FrameLayout` с фоном `primaryContainer` (светлая #B0F0D8 / тёмная #00513E, подберите из `fromSeed`), круглая или скруглённая 28dp кнопка; иконка «+» 24dp цветом `onPrimaryContainer` (#00281D / #B0F0D8) и подпись «Новая заметка» 14sp (в 2×1 и шире).
- Нажатие — пустой редактор.
- Состояния: нажато — ripple (`?android:attr/selectableItemBackground`); других нет.
