# Удаление проекта

Удаление необратимо для работы в ветке (история остаётся в git, но ветка исчезнет). Только из сессии «Офис студии».

1. Найди проект: `python3 scripts/status.py`. Имя неоднозначно (например «заметки») → покажи варианты и спроси, какой.
2. Спроси подтверждение одним сообщением: `Удалить проект «<Имя>» (<slug>) полностью? В main: да/нет. Ответь «да».`
3. После «да»: `python3 scripts/delete_project.py <slug>` (из корня, рабочее дерево чистое).
   - Проекта нет в main → GitHub (`studio-cleanup.yml`) сам удалит ветку за минуту. Проверь: `git ls-remote origin refs/heads/<slug>` пусто.
   - Проект есть в main → `python3 scripts/merge_pr.py --title "<slug>: удалить проект"` (это «да» уже получено на шаге 2). После слияния GitHub сам удалит ветку.
4. Вернись в ветку офиса: `git checkout ai-office`.
5. Отчёт 2 строки: что удалено, ветка удалена (или когда удалится). Сессию проекта Дамир архивирует сам в приложении.
