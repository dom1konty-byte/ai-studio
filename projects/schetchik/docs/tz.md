# ТЗ — Счётчик

**Цель:** простое Android-приложение, где можно считать нажатия кнопкой «+1», и число не пропадает после перезапуска.

**Для кого:** любой, кому нужно что-то посчитать (повторы, людей, круги).

## Функции MVP (по важности)
1. Кнопка «+1» — увеличивает число на 1.
2. Число крупно по центру экрана.
3. Сохранение числа после перезапуска (через `shared_preferences` — маленькое хранилище настроек на телефоне).
4. Кнопка «−1» — уменьшает число на 1, но не ниже 0.
5. Кнопка «Сброс» — обнуляет число. Без подтверждения (проще и быстрее; для пробного прогона достаточно).
6. Светлая/тёмная тема автоматически по настройке телефона.

## Экран
Один экран: число по центру, внизу «+1» (самая большая кнопка), рядом меньшие «−1» и «Сброс».

## Не делаем сейчас
- Несколько счётчиков, имена счётчиков.
- Шаг не равный 1, ввод числа вручную.
- Звук, вибрация, история, статистика.
- Ручной переключатель темы.
- Подтверждение сброса, отмена действия.
- iOS, Windows, публикация в Google Play.

## Критерии готовности
- [ ] При первом запуске показано 0.
- [ ] «+1» увеличивает число на 1 при каждом нажатии.
- [ ] «−1» уменьшает на 1; при 0 число остаётся 0.
- [ ] «Сброс» сразу ставит 0.
- [ ] После закрытия и повторного открытия приложения число то же.
- [ ] Тема меняется вместе с системной (светлая/тёмная), текст читаем в обеих.
- [ ] Число крупное, по центру; кнопки удобно нажимать на экране 360 dp шириной.
- [ ] `flutter analyze` и `flutter test` проходят без ошибок.

## Платформа
Flutter, Android. Пакет: `shared_preferences`. Интернет не нужен.
