# ТЗ — ЧистоДиск (проект «Чистка ПК»)

## Цель
Программа для Windows, которая за два нажатия («Анализ», «Очистить») убирает ненужные файлы и показывает, сколько места освободилось.

## Для кого
Для себя (Дамир). Позже, возможно, для всех.

## Функции v1 (по важности)
1. Анализ: программа считает размер каждой категории, пользователь ставит галочки.
2. Очистить: удаляет отмеченное. Итог: «освобождено X ГБ».
3. Категории очистки: временные файлы (%TEMP%, C:\Windows\Temp — только то, что доступно без админа); кэш браузеров (Chrome, Edge, Firefox, Яндекс); Корзина; кэш миниатюр; логи.
4. Браузер запущен → просьба закрыть его перед очисткой.
5. Занятые файлы (их держит другая программа) пропускаются, очистка не падает.
6. Загрузки: категория выключена по умолчанию; показывает файлы старше 30 дней с размером; галочки ставит пользователь; удаление только в Корзину.
7. Журнал удалённого: текстовый файл в %LOCALAPPDATA%; кнопка «Открыть журнал».
8. Свободное место на диске C: полоска «свободно X из Y ГБ» до и после очистки.
9. Кэш других программ (отдельные строки): Telegram Desktop, Discord, Steam (кэш шейдеров, логи), Spotify, VS Code, кэш шейдеров NVIDIA/AMD. Нет программы — строки нет.
10. Старые установщики: в Загрузках .exe/.msi/.zip подсвечены значком «установщик/архив».
11. Большие файлы: 50 самых больших файлов в Загрузках, Документах, Рабочем столе — только показ; удаление только отмеченных и только в Корзину. По умолчанию ничего не отмечено.
12. Статистика: «за всё время освобождено X ГБ» (хранится локально).

## Экраны
- Главный: список категорий с размером и галочками, кнопки «Анализ» и «Очистить».
- Загрузки: список старых файлов (имя, размер, дата) с галочками.
- Большие файлы: список (имя, папка, размер) с галочками.
- Итог: «освобождено X ГБ», сколько файлов пропущено, кнопка «Открыть журнал».

## Безопасность
- Удаляем только из белого списка известных папок кэша. Личные файлы — никогда, кроме отмеченных в Загрузках.
- Права администратора в v1 не нужны и не запрашиваются.

## Сборка
- Flutter desktop (Windows). Результат: setup.exe через Inno Setup (программа для создания установщиков).
- Установщик ставит программу и делает ярлыки на рабочем столе и в Пуске.
- setup.exe кладётся в артефакты GitHub Actions. Шагов Telegram в сборке нет.

## Не делаем в v1
Расписание; значок в трее; Windows Update и Prefetch; реестр; автозагрузка; цифровая подпись установщика.

## Критерии готовности
- `flutter analyze` и `flutter test` без ошибок; сборка в GitHub Actions зелёная.
- setup.exe ставится без прав администратора (в папку пользователя), ярлыки есть на рабочем столе и в Пуске.
- «Анализ» показывает размеры всех категорий; Загрузки выключены по умолчанию.
- «Очистить» удаляет только отмеченное; итог показывает освобождённое место.
- Файлы из Загрузок уходят в Корзину, а не удаляются насовсем.
- Запущенный браузер → появляется просьба его закрыть; занятые файлы пропускаются без ошибки.
- Журнал создаётся в %LOCALAPPDATA%, кнопка «Открыть журнал» его открывает.
- Папки вне белого списка не затрагиваются.
