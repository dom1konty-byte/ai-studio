# Бриф — Пульт студии

- О чём: программа для Windows Дамира — пульт управления студией ai-studio (своё название в окне и дизайн, не копия чужих программ). v1: доска проектов (этап, ждёт «да», статус последней сборки, кнопка скачать) — данные из GitHub (ветки проектов, projects/README.md, Actions); чат с директором каждого проекта внутри программы — программа запускает Claude Code CLI на компьютере в папке ai-studio в ветке проекта (claude -p с --resume, история каждого проекта сохраняется), агенты и правила — наш офис из .claude/; кнопки «Да» / «Поправить» на точках одобрения; «Новый проект» (идея → scripts/new_project.py → директор); вкладка «Офис» (ветка ai-office); кнопка «Продолжить на телефоне» (копирует стартовый текст для облачной сессии). Всё сохраняется в git и push, чтобы продолжать с телефона. Проверить, можно ли запускать сессии через Remote Control, чтобы чат был виден и в приложении Claude на телефоне. Нужны на компьютере: Git, Node.js, Claude Code CLI (вход аккаунтом), gh. v2: расходы/лимиты по проектам, уведомления Windows, тёмная тема. Сложный проект — позвать architect.
- Для кого: сам Дамир (один пользователь, компьютер Windows 11)
- Главное действие пользователя: вести чат с директором проекта (первый экран — чат; доска проектов, «Офис», «Новый проект» — рядом)
- Похожие примеры: свой дизайн, не копия чужих программ
- Срок: без срока
