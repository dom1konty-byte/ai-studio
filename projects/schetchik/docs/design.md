# Дизайн — Счётчик

## Экран
Один экран `Scaffold` (Material 3, `useMaterial3: true`), без AppBar, без навигации. `SafeArea`, отступы по краям 24dp.

Сверху вниз:
1. Число — по центру, занимает всё свободное место (`Expanded` + `Center`).
2. Внизу ряд: «−1» и «Сброс» (меньшие, в одну строку, поровну).
3. Под ними «+1» — на всю ширину, самая большая.

```
+------------------------+
|                        |
|                        |
|           42           |
|                        |
|                        |
| [   −1   ] [  Сброс  ] |
| [         +1         ] |
+------------------------+
```

## Цвет и тема
- `ColorScheme.fromSeed(seedColor: Color(0xFF3F51B5))` (индиго); две темы: `brightness: light` и `dark`.
- `themeMode: ThemeMode.system`. Ручного переключателя нет.
- Цвета берём из `Theme.of(context).colorScheme` (фон `surface`, число `onSurface`, ошибка `error`). Контраст ≥4.5:1 даёт M3.

## Шрифт
Системный Roboto, свой не подключаем.
- Число: `displayLarge`, размер 96sp, вес w500.
- Текст кнопок: «+1» — `headlineMedium` (28sp), «−1» и «Сброс» — `titleMedium` (16sp).

## Размеры и сетка (8dp)
- Отступы: экран 24, между кнопками 16, число от кнопок ≥24.
- «+1»: `FilledButton`, высота 96, ширина на весь экран, скругление 28 (M3 по умолчанию, можно оставить).
- «−1»: `FilledButton.tonal`, высота 56.
- «Сброс»: `OutlinedButton`, высота 56.
- Все кнопки ≥48dp. На 360dp: «−1» и «Сброс» по ~154dp.

## Тексты
«+1», «−1», «Сброс». Подсказок и заголовков нет.

## Состояния кнопок
| Кнопка | Обычное | Нажато | Неактивна |
|---|---|---|---|
| +1 | активна всегда | M3 ripple | нет |
| −1 | активна при число > 0 | ripple | при 0 (`onPressed: null`) |
| Сброс | активна при число > 0 | ripple | при 0 (`onPressed: null`) |

- Загрузка: пока `shared_preferences` читается, показываем `CircularProgressIndicator` вместо числа; кнопки неактивны.
- Пусто: это 0 (первый запуск), число «0» показано как обычно.
- Ошибка: если чтение не удалось — показываем 0 без сообщений.

## Доступность
- Число обёрнуто в `Semantics(liveRegion: true, label: 'Счёт: N')` — экранный диктор сам озвучивает изменение.
- У кнопок `tooltip`/`semanticsLabel`: «Прибавить один», «Убавить один», «Сбросить счёт».
- Контраст ≥4.5:1, кнопки ≥48dp.
- Тёмная тема: да.
