# Дизайн — Пульт студии (Windows 11, Flutter desktop, Material 3)

## Название и характер
- Заголовок окна: **«Рубка»** (капитанская рубка: отсюда видно все проекты). Запасные: «Штурвал», «Диспетчерская». Название в `title` окна и в шапке списка. Название папки/проекта остаётся `pult-studii`.
- Стиль: тёплая «бумажная» светлая тема, тёмно-бирюзовый акцент, янтарная метка «ждёт да». Без пузырей-копий Slack/ChatGPT: сообщения директора — на белой «карточке-записке» с рамкой, без аватарок; Дамира — сплошной бирюзовый блок справа. Тёмной темы нет.

## Раскладка окна
- Минимум окна 960×600, старт 1200×760. Слева панель проектов 300 px (фикс, не сжимается), справа чат (растёт). Верхней панели нет, кроме тонкой шапки чата 56 px.
- Шаг 1: левая панель = «доска» в виде списка карточек. Шаг 2: над списком вкладки «Проекты | Офис», внизу кнопка «+ Новый проект» (место 48 px зарезервировано, в шаге 1 не показывать).
- Навигация: клик по карточке проекта = открыть его чат. «Настройка» открывается вместо всего окна, пока проверка не пройдена; потом из значка шестерёнки внизу панели.

```
+--------------------------------------------------------------+
| Рубка            [обновить]| pult-studii · Разработка  [Нов.чат][Стоп]|
|----------------------------|---------------------------------|
| [Проект A      ] ЖДЁТ ДА   |  Пока ПК был выключен: 2 коммита|
|  Дизайн · сборка: успех [Скачать]  (плашка сводки)           |
| [Проект B      ]           |            [Дамир: сделай X ]   |
|  Разработка · идёт сборка  | [Директор: markdown-ответ...]   |
| [Проект C   новое]         | * директор работает...  [Стоп]  |
|  Тесты · ошибка сборки     |---------------------------------|
|                            | [ Да ] [ Поправить ]  (если ждёт)|
| (шаг 2: + Новый проект)    | [ поле ввода............][Отпр.]|
| [шестерёнка Настройка]     |                                  |
+--------------------------------------------------------------+
```

## Экраны и состояния

**1. Список проектов (доска), карточка** (высота 72, 2 строки): название (Bahnschrift 16 semibold); этап (14, вторичный цвет); справа метка «ждёт да» (янтарная `Chip`, радиус 8) и значок «новое» (точка 8 px, primary), если есть коммиты с телефона. Строка сборки: иконка + слово «идёт» (янтарь, `CircularProgressIndicator` 14 px) / «успех» (зелёный, галочка) / «ошибка» (красный, крест) / «нет сборки» (серый). Кнопка `TextButton` «Скачать» только при успехе; неактивна (серая, подсказка «артефакт старше 30 дней»), если артефакт истёк; при скачивании — индикатор, потом открывается папка. Выбранная карточка: фон `#DCEBEB`, слева полоса 4 px primary. Нажато: ripple M3. Загрузка списка: 3 серых скелета-карточки. Пусто: «Проектов пока нет. Проверь, что выбрана папка ai-studio» + кнопка «Выбрать папку». Ошибка gh/git: красная строка под шапкой списка с полным текстом ошибки и «Повторить».

**2. Чат.** Шапка: имя проекта, этап, кнопки «Новый чат» (`OutlinedButton`, с подтверждением), «Стоп» (только пока работает). Лента сверху вниз, ширина текста ≤ 760 px по центру правой части.
- Плашка сводки в начале ленты (если есть коммиты): фон `#FFF3D6`, «Пока ПК был выключен, с телефона сделано:» + список «sha дата сообщение», кнопка закрыть.
- Дамир: справа, фон primary, белый текст, радиус 16 (нижний правый 4). Директор: слева, белая карточка, рамка 1 px `#D9D0BC`, радиус 16 (нижний левый 4), текст в markdown (`flutter_markdown_plus`): заголовки, списки, код `Cascadia Mono` 13 на `#EFE9DA`, ссылки primary с подчёркиванием, текст выделяется мышью.
- Строка действий агента («агент запускает: git push»): 13, вторичный цвет, моно, без карточки.
- Индикатор «директор работает»: пульсирующая янтарная точка + «Директор работает…» под последним сообщением; поле ввода при этом активно, но отправка блокирована, пока идёт ход (кнопка «Отправить» заменена на «Стоп»).
- Ошибка процесса: красная карточка (`#FBE9E7`, рамка `#B3261E`), заголовок «Ошибка», полный текст в моно, кнопки «Повторить» и «Копировать». Не вошли в Claude: «Открой терминал и введи `claude`, войди аккаунтом».
- Отказ в разрешении: янтарная карточка «Агенту не дали выполнить: `<команда>`» + `FilledButton` «Разрешить и повторить».
- Панель «Да / Поправить» над полем ввода, только при метке «ждёт да»: `FilledButton` «Да» (зелёный `#1B6E3A`) и `OutlinedButton` «Поправить» (открывает в панели многострочное поле + «Отправить поправку» + «Отмена»). После нажатия панель исчезает до следующей проверки. Отправляются `да` / `Поправить: <текст>`.
- Поле ввода: многострочное, 1–6 строк, подсказка «Напиши директору…». Неактивно, если не пройдена настройка.
- Пусто (чата ещё нет): по центру название проекта, этап, подсказка «Напиши, что сделать» и 2 кнопки-примера: «Что сейчас по проекту?», «Продолжай».
- Нет выбранного проекта: «Выбери проект слева».

**3. Настройка.** Заголовок «Нужно поставить, чтобы Рубка работала». Список строк: Git, Node.js, Claude Code (+вход), gh (+вход), Python, папка ai-studio. Строка: иконка ok/нет, название, найденная версия или «не найдено». Для ненайденного — серый блок с командой в моно (`winget install Git.Git`, `OpenJS.NodeJS.LTS`, `GitHub.cli`, `Python.Python.3.12`, Claude Code — команда с code.claude.com) и кнопка «Копировать». Внизу `FilledButton` «Проверить снова» (загрузка: индикатор на кнопке). Всё в порядке — экран закрывается сам.

## Шрифты
Всё есть в Windows 11, ничего не качаем. Заголовки, названия проектов, метки: **Bahnschrift** (запас: Segoe UI). Текст: **Segoe UI Variable** (запас: Segoe UI). Код: **Cascadia Mono**.
Размеры: заголовок окна/экрана 22; название проекта 16; текст чата и поля 15 (высота строки 1.5); подпись, этап, время 13; код 13.

## Сетка, отступы, радиусы
- Сетка 8 px: отступы 8 / 16 / 24; поля окна 24; между сообщениями 16; внутри карточки 12×16.
- Радиусы: карточки и сообщения 16, кнопки и метки 8, поле ввода 12, панель действий 12.
- Кнопки и кликабельные строки ≥ 48 px высотой; фокус с клавиатуры — рамка 2 px primary.

## Горячие клавиши
Enter — отправить; Shift+Enter — новая строка; Esc — Стоп (во время работы) или закрыть поле «Поправить»; Ctrl+K — фокус на поле ввода; F5 — обновить доску. Во время работы директора Enter не отправляет (текст остаётся в поле).

## Состояния кнопок (общее)
Обычное: заливка/рамка по роли. Нажато: M3 ripple и затемнение 12%. Неактивно: фон `#E3DCCB`, текст `#76706A` (не несёт смысла без подсказки-`Tooltip` причины). Загрузка: индикатор 16 px вместо иконки, кнопка неактивна. Пусто и ошибка — как в экранах выше.
